Before you test

    Log the test

    One row per tester who was exposed to the page, including people who bounced. That is your denominator. Never log someone’s name.

    Add a tester

    Observed behavior only, for example “hesitated at the confidence question”. No names.

    Pull in this device’s runs

    If testers used this browser, import their plan runs so you don’t retype them. Each run imports once.

    Count them from the inbox. A sent email is stronger evidence than a click.
